# No. 7 insert V0.1.8

本版将圣诞船池与扫雪更新为 WG 15.11 的 2026 圣诞及新年活动内容。

## 圣诞船池

- 按 WG 开发博客替换 28 艘舰船，共 143 艘；稀有及 X 级、VIII–IX 级、V–VIII 级分别为 42、53、48 艘。
- 普通、超大号和超级圣诞礼物补给箱共用本期名单，按官方概率分档展示；继续支持港口拥有状态核对及筛选。
- 舰船 ID、中英文名、等级、国家及舰种对照 WG 官方目录，来源按钮指向本期开发博客。

## 扫雪奖励与兑换

- V、VI、VII 级单舰分别奖励 700、750、800 煤炭。
- VIII、IX 级单舰分别奖励 70、80 钢铁；超级舰船奖励 200 钢铁。
- X 级单舰奖励 1 枚节日代币。
- 1 枚代币可规划兑换普通圣诞礼物补给箱或 375,000 银币；5 枚可规划兑换超大号圣诞礼物补给箱。
- 总览新增煤炭统计，同步更新各等级奖励、经验要求及额外领取规则。统计为当前港口的活动总收益，不扣除游戏内已领取奖励。

- **便携版**：`No.7.insert.0.1.8.exe`，无需安装。
- **校验文件**：`SHA256SUMS.txt`。
