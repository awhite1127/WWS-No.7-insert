# 战舰世界 七号插
# WWS No. 7 insert

![No. 7 insert 图标](source/src/assets/app-icon.png)

**No. 7 insert** 是面向《战舰世界》WG 服的开源战绩查询与对局助手。当前源码版本为 **V0.1.7**，首次公开版本为 **V0.1.1**。

## 下载完整程序

Windows 0.1.7 安装版、便携版和 SHA-256 校验值位于 `release/0.1.7`。安装版支持选择安装目录并创建快捷方式；便携版可直接运行。下载见 [V0.1.7 发布页](https://github.com/awhite1127/WWS-No.7-insert/releases/tag/V0.1.7)，完整说明见 [0.1.7 更新说明](docs/releases/0.1.7.md)。公开历史版本见 [GitHub Releases](https://github.com/awhite1127/WWS-No.7-insert/releases)。

源码在本仓库的 [source](source) 文件夹；打包文件通过 GitHub Releases 分发，避免把大型二进制文件写入 Git 历史。

- **两页战绩面板**：我的战绩与玩家战绩通过标题右侧的“总览 / 详细”切换。总览页展示账号战绩与趋势；详细页移除账号卡，压缩舰种汇总，把主要空间留给详细舰船查询，略微放大数据、表头和筛选文字。
- **全历史战绩趋势**：固定展示累计胜率、个人评分 PR、场均伤害和场均经验四项，只使用已有本地记录；每天保留最后一次查询，不补造未记录的历史，也不再按 180 天或 1000 条截断。
- **个人评分 PR**：总览、趋势、舰种汇总及单舰列表加入 PR，采用 WoWS Numbers 的公开计算公式和舰船期望值；按其八档评分颜色显示，支持单舰 PR 排序。期望值版本随本版打包，缺少可计算数据时显示“—”，删除数值下方的覆盖百分比描述。
- **舰种统计**：按 DD、BB、CV、CL、SS 汇总场次、胜率、场均伤害、经验、击沉和 PR；胜率沿用原有颜色规则，场均数据按场次加权，PR 汇总实际与期望数据后计算。CL 对应 WG 的巡洋舰分类。
- **游戏内业力**：七号插卡片通过 WoWS Karma 的 In-Game（gameKarma）接口异步读取，姓名右上角只显示数字；0 正常显示，暂不可用显示“—”，第三方数据可能有同步延迟。个人战绩页移除字母头像占位。
- **公告详情弹窗**：舰船调整和版本公告在独立弹窗中显示全文，正文可滚动，支持关闭按钮、Esc 或双击弹窗外关闭，保留中文详情、失败重试和官网原文入口。
- **圣诞船池分档**：依据 WG 官方概率表，按稀有及 X 级（42 艘）、VIII–IX 级（53 艘）、V–VIII 级（48 艘）排序分类；显示普通、超大号和超级圣诞礼物补给箱的分档概率，保留拥有状态及多条件筛选。
- **模块等高与空间调整**：战绩总览、历史积累提示和排位记录保持等高；扫雪总览、等级奖励及兑换规划切换时不再挤压下方区域。查询卡片、军团成员列表和七号插等待页的布局同步整理。
- **七号插读取改进**：24 人批量接口部分失败时只重试缺失账号，临时限流和网络错误可恢复；对局单舰只请求当前舰船，舰船资料跨启动缓存并发读取，成功结果在分组失败时仍保留。
- **对局展示与监听**：双方玩家逐行展示账号和单舰战绩，显示双方公开账号平均胜率；增加读取状态提示，把日志移到标题旁，降低稳定对局时的重复扫描，游戏内浮层和呼出键在识别对局后启动。
- **GitHub 更新下载修复**：改用 Electron 网络接口处理系统代理；连接或连续无数据等待达到 30 秒时中止，临时错误自动重试一次，清理失败残留并显示可操作的网络提示，继续校验下载大小与 SHA-256。
- **验证**：85 项自动测试通过；完成深浅主题、多种窗口尺寸、战绩分页与筛选、业力数字显示的界面检查，并使用实际 Electron 完整下载和校验 GitHub 公开安装包。安装启动未在测试中执行。

## 功能

- 支持亚服、欧服、美服玩家战绩和军团查询
- 展示总体战绩、单舰战绩和排位赛季数据
- 自动扫描游戏 `replays` 及其子目录中的 `tempArenaInfo.json`，并选取最近写入的文件
- 七号插按舰种排序双方阵容，展示账号与单舰数据及读取日志
- 七号插首页显示游戏路径与对局文件识别状态，切换到最近写入的对局文件并在内容更新后刷新
- 数据检索提供箱子查询，搜索补给箱并查看官网公布的奖励与概率
- 数据检索提供最近一期圣诞船池，可按舰种、国家、等级和拥有情况筛选；首次授权后可与港口舰船核对
- 支持真实 12v12 对局、刷新数据和游戏内透明覆盖层
- 支持 WG 账号授权、个人战绩、港口舰船活动奖励汇总
- 支持黑色与白色主题、自定义或关闭覆盖层呼出按键

## 从源码运行

需要 Node.js 与 npm。在 [source/.env.example](source/.env.example) 的基础上创建 `source/.env.local`，填入自己的 WG `application_id`，再执行：

```powershell
cd source
npm ci
npm run dev
```

`source/.env.local` 已排除在 Git 之外。程序不会在设置页显示该值。

npm run dist -- --config.directories.output=../release/0.1.7

## 舰船配装规划器

左侧「舰船配装」覆盖战列舰、巡洋舰、驱逐舰、航空母舰和潜艇。内置 15.8 数据快照含 936 艘舰船、舰种专属技能树、106 种升级品和特殊舰长；不包含高清模型。技能与升级品图标加压缩数据合计约 1 MB，进入页面才加载。

- 总点数固定 21 点，四层技能自由加点。技能说明悬停显示，触发控制仅在选中技能后显示于对应图标下。升级品与配装方案通过浮层下拉选择，不挤压技能区域。研发模块默认完全体，消耗品沿用推荐方案的雷达/烟雾等配置。
- 舰船按国家、舰种、详细舰船筛选：银币船仅展示十级和超级战舰，加值及特殊舰船保留全部等级。
- 舰长选择为普通、特殊、对应国家的传奇舰长；特殊舰长不显示人名，不同强化组合按技能配置区分。传奇天赋随国家切换，强化技能单独标记。名称优先采用可核验的 WG 中文用法，缺少官方中文的名称保留 WG 原名。
- 玩法模板支持生存、主炮、副炮、鱼雷及功能等方向。优先按社区线路及特殊舰船匹配，其余舰船使用规则参考；两者在界面中区分标记，可查看当前模板的来源及源资料更新时间。
- 参数实时展示基础值、配装后数值和变化，包含生命值、隐蔽、航速、主副炮、鱼雷、舰载机及潜艇参数；支持适用的理论 DPM。条件技能在已选技能下通过剩余生命值、触发开关等控制；未折算进参数的复杂效果另列说明。
- 本机自动保留草稿，最多保存 100 份方案；使用方案代码复制分享和导入。排位模式不启用传奇舰长天赋，也不直接套用社区随机战方案。

点击「更新数据」在线检查公开游戏数据版本，下载并校验后写入本机缓存；计算在本地完成，断网仍可使用内置快照或已缓存数据。更新失败保留当前数据。新版本出现未内置的图标时使用通用图标，名称和效果仍来自更新后的数据。数值是配装计算结果，实际对局还受目标、命中率、触发条件等影响。

推荐规则于 2026-10-01 参考 [Gameplay Helpers 社区指南](https://www.wowbuilds.com/guide/captain-builds)（页面标注更新于 2026-08-26）调整，覆盖五舰种、28 个线路或玩法配方，当前匹配约 207 艘舰船（含黑色同型船）。其余舰船保留明确标记的规则参考。源资料针对随机战，排位仅保留未经当期赛制审核的规则参考。

主要差异包括：日系雷驱与八级以上炮驱分流；施里芬加入惯性引信和维修专家，自由保留防火；德系战列以主炮生存为优先；英系轻巡烟雾和雷达方案切换对应消耗品；纯 AP、SAP 及跳弹机不选无效的点火、AP 或俯冲轰炸技能。低级巡洋无维修时提前学习肾上腺素。航母源图含旧技能与旧成本，因此按内置 15.8 技能表适配，而非原样复制截图；社区来源不代表原作者认可这些适配。

来源入口分别链接到[施里芬](https://www.wowbuilds.com/guide/tech-tree-branches-analogous-premiums-and-t10-ships/battleships/km-bcs-schlieffen-line)、[日系雷驱](https://www.wowbuilds.com/guide/tech-tree-branches-analogous-premiums-and-t10-ships/destroyers/ijn-torpedoboat-dds-shimakaze-line)、[英系轻巡](https://www.wowbuilds.com/guide/tech-tree-branches-analogous-premiums-and-t10-ships/cruisers/rn-cls-minotaur-line)及其他具体线路；技能适用性对照 [Wargaming 技能说明](https://wiki.worldofwarships.com/Ship:List_of_Commander_Skills)和内置游戏数据校验。推荐仍可自由调整，更新游戏数据不会自动替换已维护的模板规则。

真实桌面交互验证：构建后运行 `npm run test:planner-ui`，会短暂显示测试窗口，使用独立临时配置，并在 `previews` 目录生成宽屏和窄屏截图。

舰船数据每次启动自动联网检查一次，仅有新版本时下载并缓存。设置提供全局“检查舰船数据”入口，配装页面不再单独显示更新按钮。配装、七号插和单舰战绩共用更新后的舰名及基础信息；远端尚未收录的船保留 WG 接口或对局文件名称回退。检查失败继续使用本地数据，下次启动或手动检查再尝试。推荐方案由程序本地维护，随程序版本更新。新船需要等级、类型、技能和升级品等信息才能参与配装，更新范围不限于船名。

维护内置快照：在 `source` 目录运行 `npm run sync:planner`，然后重新构建。数据来自 [WoWS ShipBuilder](https://github.com/WoWs-Builder-Team/WoWs-ShipBuilder) 使用的公开数据服务；游戏版本变化后应复核规则和推荐模板。15.8 快照中缺少舰载机「战斗机动专家」的技能位置，因此按官方 15.2 公告补入航空母舰二级技能位置。

本项目在开发过程中参考了以下公开资料、服务和开源项目：

- [WoWS Karma](https://wows-karma.com/)（[源码](https://github.com/SakuraIsayeki/WOWS-Karma)）：使用其按服务器提供的玩家信息接口中的 In-Game / gameKarma 字段，展示游戏内业力。感谢 Sakura Isayeki、Nodsoft Systems 及相关维护者提供这一服务。
- [ApeRadar 海猴雷达](https://github.com/iwvw-per/ApeRadar)（[项目主页](https://lxdev.org/aperadar/)）：在代码结构、对局信息组织、玩家战绩卡片布局和界面设计等方面提供了参考与启发；感谢原作者及贡献者的开源分享。
- [Wargaming Developer API](https://developers.wargaming.net/) 与战舰世界官方公告：提供账号、军团、舰船战绩以及补给箱与活动概率等基础资料。
- [WoWS ShipBuilder](https://github.com/WoWs-Builder-Team/WoWs-ShipBuilder) 与 [DataConverter](https://github.com/WoWs-Builder-Team/DataConverter)：配装数据结构、公开数据快照和技能/升级品图标的来源与参考。游戏数据和图标属于 Wargaming，相关开源代码按各项目许可证使用。
- [Electron](https://www.electronjs.org/) 与 [Vue](https://vuejs.org/) 等开源工具及其贡献者：支持本项目的桌面运行、界面和构建。

感谢以上项目的作者、维护者和社区贡献者。正是这些公开资料、接口及设计经验，让七号插得以持续完善；各项目的名称、代码和资源权益归各自权利人所有。

配装界面改进：强化技能用左上角白星标记；条件控制位于技能框内，各行按潜在控件预留固定空间，加点不改变行位置。方案仅显示流派名，采用顶部方案栏与右侧独立滚动参数栏。消耗品参数按实际装备显示“伤害控制小组”“维修小组”“监视雷达”等名称。战列舰通用生存流采用用户截图中的 21 点选择，防空射程严格大于 5.8 km 的战列舰额外提供防空生存流。

舰船检索与方案选择整合至标题右侧的紧凑工具栏；方案说明与保存分享通过浮层展开。1600×900、1100×900 和 1280×720 下四层技能无需整页滚动即可显示，参数列表独立滚动。查询历史为空时，提示文本位于标题下方的顶部位置。

舰船配装界面统一中文与数字字体、字号层级和行距；升级品与技能区域和右侧参数卡片上下对齐，技能行随窗口高度分配空间，触发条件选择保持布局稳定。参数仍独立滚动，1280×720、1100×900、1600×900 的四层技能与底部说明均完整可见。

配装检索排除 78 个黑五、涂装、联动及指定复制版本，仅保留原版索引（当前可选 523 艘）。施里芬、自由各保留用户指定的唯一 21 点副炮加点；移除配装页服务器切换，压缩检索栏，将传奇天赋入口移至舰长类型旁并浮层展开。浅色主题统一卡片、技能、输入框和参数配色。
