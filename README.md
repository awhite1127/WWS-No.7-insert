# 战舰世界 七号插
# WWS No. 7 insert

![No. 7 insert 图标](source/src/assets/app-icon.png)

**No. 7 insert** 是面向《战舰世界》WG 服的开源战绩查询与对局助手。当前源码版本为 **V0.1.5**，首次公开版本为 **V0.1.1**。

## 下载完整程序

Windows 安装版和便携版可从 [V0.1.5 发布页](https://github.com/awhite1127/WWS-No.7-insert/releases/tag/V0.1.5) 下载；本地构建和 SHA-256 校验值位于 `release/0.1.5`。V0.1.4 文件归档于 `release/0.1.4`，预览构建位于 `release/previews`。安装版支持选择安装目录并创建快捷方式；便携版可直接运行。

源码在本仓库的 [source](source) 文件夹；打包文件通过 GitHub Releases 分发，避免把大型二进制文件写入 Git 历史。

## 功能

- 支持亚服、欧服、美服玩家战绩和军团查询
- 展示总体战绩、单舰战绩和排位赛季数据
- 自动扫描游戏 `replays` 及其子目录中的 `tempArenaInfo.json`，并选取最近写入的文件
- 七号插按舰种排序双方阵容，展示账号与单舰数据、胜率走势图及读取日志
- 七号插首页显示游戏路径与对局文件识别状态，切换到最近写入的对局文件并在内容更新后刷新
- 数据检索提供箱子查询，搜索补给箱并查看官网公布的奖励与概率
- 数据检索提供最近一期圣诞船池，可按舰种、国家、等级和拥有情况筛选；首次授权后可与港口舰船核对
- 支持 12v12 模拟对局、刷新数据和游戏内透明覆盖层
- 支持 WG 账号授权、个人战绩、港口舰船活动奖励汇总
- 支持黑色与白色主题、自定义或关闭覆盖层呼出按键

程序只读取本地对局文件及 WG 官方接口，不修改游戏文件。

## 从源码运行

需要 Node.js 与 npm。在 [source/.env.example](source/.env.example) 的基础上创建 `source/.env.local`，填入自己的 WG `application_id`，再执行：

```powershell
cd source
npm ci
npm run dev
```

`source/.env.local` 已排除在 Git 之外。程序不会在设置页显示该值。

## 测试与构建

```powershell
cd source
npm test
npm run build
npm run dist
```

`npm run dist` 默认在根目录的 `release` 文件夹生成安装版、便携版和解压版；本次 V0.1.5 成品已归入 `release/0.1.5`。图标源文件为 [app-icon.png](source/src/assets/app-icon.png)，Windows 图标由 [generate-icon.ps1](source/build/generate-icon.ps1) 生成。
